# LifeMaker

スマホで遊ぶ模様替えゲーム。家具を自由に置いて部屋を作り、一緒に住むキャラクターとの暮らしを楽しむ。

遊ぶ: https://arata-a3.github.io/LifeMaker/

## いまできること（v0.4.0）

- 3D の部屋（6m 四方、12×12 マス）に家具を置く
  - 下の一覧から家具を押すと、空いている場所に置かれる
  - 家具をドラッグで動かす（マス目にそろう）、ダブルタップか「回転」で 90° ずつ回す、「しまう」で片付ける
  - 「色」で家具の色を部位ごとに変える（例: ソファの布・クッション・脚）。最近使った色・ほかの家具と同じ色・色の候補・色合い／鮮やかさ／明るさの微調整・自由な色から選べ、元の色にも戻せる
  - 色の画面を開いてもカメラは動かない。家具が画面に隠れるときだけ、隠れない分だけ静かにずらす
  - 本棚の本は「本 1・本 2・本 3」の 3 冊ずつのまとまりで色が変わる
  - ラグは上に家具を重ねて置ける。ほかの家具どうしが重なると、足元の印が赤くなる（置くことはできる）
- 小物（マグカップ・積んだ本・花びん・置き時計・卓上ライト・小さな鉢植え）: テーブル・ローテーブル・テレビ台・本棚・クローゼットの上に載る。家具を動かす・回すと、上の小物もいっしょに動く
- 壁掛け（絵・壁掛け時計・ウォールシェルフ・窓・鏡）: 見えている壁に掛かり、ドラッグで壁に沿って横・上下に動かせる。別の壁まで動かすと掛け替わる
- 床と壁: 「床・壁」タブで柄（床: フローリング・タイル・カーペット・畳、壁: 無地・ストライプ・レンガ・腰壁）と色を変える
- 元に戻す／やり直す（左上の ↶ ↷、PC は Ctrl+Z / Ctrl+Y）。置く・動かす・回す・しまう・色・床と壁・プリセットの呼び出しを 100 手まで戻せる
- 家具の一覧を名前やタグで絞り込む（ひらがなでカタカナの名前も探せる）
- 部屋のプリセット: 今の部屋（家具・色・床と壁）に名前を付けて保存し、あとで呼び出す（30 個まで。同じ名前なら上書き）
- 何もない所をドラッグで部屋を回す、2 本指で拡大縮小・回転（PC はホイールで拡大縮小）
- 手前側の壁は自動で隠れる
- 部屋は自動で保存され、次に開いたときに元に戻る
- 設定: 明るさ（端末に合わせる・ライト・ダーク）、部屋を空にする、全てのデータを消す
- ホーム画面に追加できる（PWA）

PC ではキーボードも使える（R: 回転、Delete: しまう、Esc: 選択をやめる）。

## 作り

- ブラウザで動く（HTML / CSS / JavaScript）。3D は [three.js](https://threejs.org/) r187（`lib/three.module.min.js`、MIT ライセンス: `lib/three.LICENSE`）
- 家具は今のところ箱や円柱を組み合わせた積み木風。あとからモデルに差し替える
  - 部品の面がぴったり重なるとチラつく（Z ファイティング）ので、2〜5mm ずらして重ねる。テストで重なりがないか確かめている
- 公開: GitHub Pages（main ブランチの `/`）
- テスト: `node tests/run.mjs`（ヘッドレス Chrome で動かす）。`node tests/run.mjs <フォルダ>` で各画面サイズのスクリーンショットも撮る

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/app.js` | 家具の定義、3D の部屋、操作、保存 |
| `sw.js`, `manifest.webmanifest` | ホーム画面に追加・オフライン用 |
| `tests/run.mjs` | 自動テスト |

## コンセプト

- 部屋づくりが主役。自由に置けて、色も変えられて、気に入った部屋は取っておける。
- 住人がいることで「作った部屋が使われる」楽しさが生まれる。住人は置いた家具で座ったり寝たりして暮らす。
- 暮らすとお金と友好度が貯まり、それで家具が増えていく。部屋づくり → 暮らし → 家具が増える → また部屋づくり、の繰り返しで遊ぶ。

## 遊びの流れ（基本のループ）

1. 家具を置いて部屋を作る（模様替えモード）
2. 住人が部屋で暮らす様子を眺める（暮らしモード）
   - 住人は家具を使う（ベッドで寝る、椅子に座る、本棚で本を読む など）
   - 住人の好みに合う家具・色・部屋の雰囲気だと友好度が上がりやすい
3. 暮らしの中でお金（コイン）が貯まる
4. コインで家具を買う／友好度が上がると家具をもらえる
5. 新しい家具で 1. に戻る

## 機能

### 部屋づくり

- 家具を置く・動かす・回転する・しまう（ドラッグ操作、スマホの指で快適に）
- マス目（グリッド）に沿って置く
- 床置き・壁掛け・机の上に置く小物、の3種類の置き方（v0.4.0）
- 重ね置きをある程度許す
  - 机や棚の上に小物を置ける（「上に置ける」家具を決めておく。家具の定義の `top` が天面の高さ）
  - 家具どうしのはみ出し・少しの重なりは許す（完全に同じ場所は不可、など程度は調整）
- 家具の色を部位ごとに変える
  - 色の候補から選ぶ・微調整する・自由に選ぶ
- 床・壁の柄や色を変える（v0.3.0）
- 元に戻す／やり直す（v0.3.0）

### 部屋のプリセット

- 今の部屋のレイアウト（家具・位置・向き・色・床と壁）を名前を付けて保存する
- 保存したレイアウトを呼び出して部屋に反映する
- 保存したレイアウトをもとに新しい部屋を作る
- 持っていない家具が含まれる場合の扱い（置かない／影で表示する など）は未決

### 家具の検索

- 家具にタグを付ける（例: 種類「椅子」「照明」、雰囲気「ナチュラル」「レトロ」、色、置き場所「壁」）
- タグで絞り込む・名前で検索する
- 並べ替え（新しく手に入れた順、種類順 など）
- お気に入り登録

### 住人

- 部屋で自由に動き、家具を使って暮らす
- 好み（好きな家具の種類・色・雰囲気）を持つ
- 友好度
  - 好みの家具を使う・好みの部屋で過ごすと上がる
  - 一定の値で家具をもらえる、セリフや行動が増える
- 1人から始めて、増やせるかは未決

### お金と家具の入手

- 暮らしの中でコインが貯まる（時間経過、住人の満足度 など）
- お店で家具を買う
- 友好度のごほうびで家具をもらう
- 最初から持っている家具は少しだけ

## 最初に作る範囲（試作版） — v0.2.0 でひととおりできた

まずは「置いて・色を変えて・保存できる」部屋づくりの手触りを確かめる。

1. 1部屋に家具を置く・動かす・回転する・しまう
2. 家具の色を変える
3. タグで家具を絞り込む
4. 部屋の状態を保存して、次に開いたとき元に戻る
5. 部屋のプリセットを保存・呼び出す

住人・お金・お店はその次に足す。

## データの持ち方（案）

- 家具の定義: ID、名前、大きさ（マス数）、置き方（床・壁・上置き）、上に物を置けるか、色の候補、タグ、値段、住人が使うときの動作
- 部屋: 床と壁、置いた家具の一覧（家具ID、位置、高さ、向き、色）
- プリセット: 名前と部屋の中身のコピー
- 住人: 名前、好み、友好度
- 持ち物: 持っている家具と数、コイン

## 未決のこと

- 重ね置きをどこまで許すか
- 住人を増やせるか、どこから来るか
- 部屋を複数持てるか（プリセットとは別に）
- 家具・住人の 3D モデルをどう用意するか（自作、CC0 などの素材）

## 決まったこと

- 見せ方は 3D（three.js）。部屋を回して見られ、色変え・重ね置きと相性がよい
- ブラウザで動く形にして、GitHub Pages で公開する
- 家具の色は、候補から選ぶのも自由に選ぶのもできるようにする
