# LifeMaker

スマホで遊ぶ模様替えゲーム。家具を置いて部屋を作り、一緒に住むキャラクターとの暮らしを楽しむ。

遊ぶ: https://arata-a3.github.io/LifeMaker/

v0.8.0 から、斜め上から見た 2D の部屋になった。それまでの 3D 版は `3d` ブランチと `v0.7.0` のタグに残している。

## いまできること（v0.10.6）

- 斜め上から見た部屋（5m 四方、10×10 マス）に家具を置く
  - 家具は 17 種類: ベッド・ソファ・いす・テーブル・ローテーブル・机・本棚・クローゼット・チェスト・サイドテーブル・テレビ台・スタンドライト 2 種・観葉植物 2 種・花びん（大）・ラグ
  - 小物（テレビ・花びん）: テーブル・机・テレビ台・チェストなどの上に載る。家具を動かす・向きを変えると、上の小物もいっしょに動く。テレビは置くとテレビ台の上を先に探す
  - 壁掛け（窓 2 種・絵）: 窓枠・額縁の四角が、壁の上の四角にぴったり合う（カーテンなどの飾りは外にはみ出す）。壁に沿って横・上下にドラッグで動かす。部屋の角をまたいで動かすか「⇆ 反対の壁」で、反対の壁に掛け替える
  - 「🎨 色」で家具の色合い・鮮やかさ・明るさを変える。「ぜんぶ」か、部位（例: ベッドの布団・枠・シーツ・枕、ソファの布・脚・クッション）ごとに変えられる。よく使う色合い（赤み・青み・モノクロなど）は、その家具の見本から選べる。元の色にも、開いたときの色にも戻せる
  - 下の一覧から家具を押すと、空いている場所に置かれる
  - 家具をドラッグで動かす（マス目にそろう）。ダブルタップか「⇆ 向き」で左右の向きを変える、「しまう」で片付ける
  - 家具は絵の形どおりに選べる（透明な所を押しても選ばれない）
  - ほかの家具と重なると、足元の印が赤くなる（置くことはできる）。ラグは上に家具を重ねて置ける
- 何もない所をドラッグで部屋を動かす。2 本指（PC はホイール）で拡大縮小
- 住人: 部屋に 1 人住んでいて、家具を避けて歩き回る。歩く向きで前向き・後ろ姿が変わる。右足・立ち・左足・立ちの 4 拍で、一歩ごとに体が上下し、少し傾く
  - ソファ・いすに座る、ベッドで寝る（💤）、本棚・机・植物などを眺める（正面がふさがっていれば横や後ろから）
  - 押すと笑って話す。置いたばかりの家具には手を振って見に行く
  - 座っている家具を動かすと立ち上がり、立っている所に家具を置くと横によける
  - 設定で名前を付けられる。隠すこともできる
- 元に戻す／やり直す（左上の ↶ ↷、PC は Ctrl+Z / Ctrl+Y）
- 部屋のプリセット: 今の部屋に名前を付けて保存し、あとで呼び出す（30 個まで。同じ名前なら上書き）
- 部屋は自動で保存され、次に開いたときに元に戻る
- 設定: 住人の名前・表示、明るさ（端末に合わせる・ライト・ダーク）、部屋を空にする、全てのデータを消す
- ホーム画面に追加できる（PWA）

PC ではキーボードも使える（R: 向き、C: 色、Delete: しまう、Esc: 選択をやめる）。

### 3D 版にあって、2D 版にまだないもの

小物のマグカップ・積んだ本・置き時計など、壁掛けの時計・鏡・棚、床と壁の柄、家具の検索。絵がそろったものから戻していく。

## 作り

- ブラウザで動く（HTML / CSS / JavaScript）。部屋は canvas に描く。外部のライブラリは使っていない
- 住人と家具の絵は画像生成AIで作る。手順とプロンプトは [art/README.md](art/README.md)
  - 生成した画像は `art/source/` に置き、`python tools/cut_sprites.py` で背景を抜いて切り出す（`art/sprites/` に元の大きさ、`img/` にゲーム用の軽い WebP）
  - 続けて `python tools/sprite_meta.py` で、床に着く 3 つの角と、色の部分（`img/<名前>_parts.png`、名前と代表の色は `img/sprites.json`）を求める
  - 家具の絵は「正面が左下」で描く。右下向きは左右反転で作る
  - 部屋の床・壁は、コードで描いている
  - 床は 30 度の見下ろし（横 2 に対して縦 1.15）。AIの絵がこの角度で描かれているため
  - 床に着く角が分かる家具は、縦横同じ倍率で縮め、脚の先の左端・右端を足元の四角の左端・右端に、いちばん下の脚の先を床に合わせる（天板の出っ張りに惑わされない。引き伸ばしはしない）。丸いテーブルは、脚が天板より内側にあるので、脚の広がりを枠の幅の 75%（`legInset`）に合わせる
  - 壁掛けは、本体（窓枠・額縁の正面）の 4 つの角を、壁の上の四角に合わせる。角の位置は `tools/sprite_meta.py` の `WALL_FACES` に目で読み取って書いている（絵を作り直したら読み取り直す）。窓（アーチ）のように左の壁向きで描かれた絵は、右の壁に掛けるときに左右反転する
  - ラグは平らなので、4 つの角を床の四角に合わせて変形する
  - 植木鉢・ライト・花びんなどは、高さ（`fitHeight`）で大きさを決め、底の真ん中を枠の真ん中に置く
  - 動かない部分（部屋・壁掛け・敷物・家具の影）は描いて取っておき、住人が止まっている間は描き直さない
- 公開: GitHub Pages（main ブランチの `/`）
- テスト: `node tests/run.mjs`（ヘッドレス Chrome で動かす）。`node tests/run.mjs <フォルダ>` で各画面サイズのスクリーンショットも撮る

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/app.js` | 家具の定義、部屋の描画、操作、住人、保存 |
| `img/` | ゲームで使う絵（WebP） |
| `art/` | 絵の作り方、生成した元の画像、切り出した画像 |
| `tools/cut_sprites.py` | 生成した画像から背景を抜いて切り出す |
| `tools/sprite_meta.py` | 床の角と色の部分を求める |
| `sw.js`, `manifest.webmanifest` | ホーム画面に追加・オフライン用 |

## コンセプト

- 部屋づくりが主役。自由に置けて、色も変えられて、気に入った部屋は取っておける。
- 住人がいることで「作った部屋が使われる」楽しさが生まれる。住人は置いた家具で座ったり寝たりして暮らす。
- 暮らすとお金と友好度が貯まり、それで家具が増えていく。部屋づくり → 暮らし → 家具が増える → また部屋づくり、の繰り返しで遊ぶ。

## 遊びの流れ（基本のループ）

1. 家具を置いて部屋を作る（模様替えモード）
2. 住人が部屋で暮らす様子を眺める（暮らしモード）
   - 住人は家具を使う（ベッドで寝る、椅子に座る、本棚で本を読む など）
   - 住人の好みに合う家具・色・部屋の雰囲気だと友好度が上がりやすい
3. 暮らしの中でお金（コイン）が貯まる
4. コインで家具を買う／友好度が上がると家具をもらえる
5. 新しい家具で 1. に戻る

## 機能

### 部屋づくり

- 家具を置く・動かす・回転する・しまう（ドラッグ操作、スマホの指で快適に）
- マス目（グリッド）に沿って置く
- 床置き・壁掛け・机の上に置く小物、の3種類の置き方（v0.4.0）
- 重ね置きをある程度許す
  - 机や棚の上に小物を置ける（「上に置ける」家具を決めておく。家具の定義の `top` が天面の高さ）
  - 家具どうしのはみ出し・少しの重なりは許す（完全に同じ場所は不可、など程度は調整）
- 家具の色を部位ごとに変える
  - 色の候補から選ぶ・微調整する・自由に選ぶ
- 床・壁の柄や色を変える（v0.3.0）
- 元に戻す／やり直す（v0.3.0）

### 部屋のプリセット

- 今の部屋のレイアウト（家具・位置・向き・色・床と壁）を名前を付けて保存する
- 保存したレイアウトを呼び出して部屋に反映する
- 保存したレイアウトをもとに新しい部屋を作る
- 持っていない家具が含まれる場合の扱い（置かない／影で表示する など）は未決

### 家具の検索

- 家具にタグを付ける（例: 種類「椅子」「照明」、雰囲気「ナチュラル」「レトロ」、色、置き場所「壁」）
- タグで絞り込む・名前で検索する
- 並べ替え（新しく手に入れた順、種類順 など）
- お気に入り登録

### 住人

- 部屋で自由に動き、家具を使って暮らす
- 好み（好きな家具の種類・色・雰囲気）を持つ
- 友好度
  - 好みの家具を使う・好みの部屋で過ごすと上がる
  - 一定の値で家具をもらえる、セリフや行動が増える
- 1人から始めて、増やせるかは未決

### お金と家具の入手

- 暮らしの中でコインが貯まる（時間経過、住人の満足度 など）
- お店で家具を買う
- 友好度のごほうびで家具をもらう
- 最初から持っている家具は少しだけ

## 最初に作る範囲（試作版） — v0.2.0 でひととおりできた

まずは「置いて・色を変えて・保存できる」部屋づくりの手触りを確かめる。

1. 1部屋に家具を置く・動かす・回転する・しまう
2. 家具の色を変える
3. タグで家具を絞り込む
4. 部屋の状態を保存して、次に開いたとき元に戻る
5. 部屋のプリセットを保存・呼び出す

住人・お金・お店はその次に足す。

## データの持ち方（案）

- 家具の定義: ID、名前、大きさ（マス数）、置き方（床・壁・上置き）、上に物を置けるか、色の候補、タグ、値段、住人が使うときの動作
- 部屋: 床と壁、置いた家具の一覧（家具ID、位置、高さ、向き、色）
- プリセット: 名前と部屋の中身のコピー
- 住人: 名前、好み、友好度
- 持ち物: 持っている家具と数、コイン

## 未決のこと

- 重ね置きをどこまで許すか
- 住人を増やせるか、どこから来るか
- 部屋を複数持てるか（プリセットとは別に）

## 決まったこと

- 見せ方は 2D の斜め上から（クォータービュー）。絵は画像生成AIで作り、アニメ調でくすんだ色にそろえる（v0.8.0 で 3D から変更）
- ブラウザで動く形にして、GitHub Pages で公開する
- 家具の色は、絵全体の色合い・鮮やかさ・明るさを変える形にする（AIの絵は部位ごとに色を分けられないため）
